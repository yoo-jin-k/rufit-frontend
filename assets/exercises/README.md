- 제공: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db)
- 고정 커밋: `a859101d633a01c4a1a920d6a8ce41dabba0705f`
- 저장소가 명시한 라이선스: Unlicense. 원문은 [UPSTREAM-LICENSE.md](UPSTREAM-LICENSE.md).
- 18개 종목의 두 번째 동작 사진을 원본 JPEG 그대로 보관한다. 총 약 1.13 MB.
- 종목별 원본 URL, 제공자 종목 ID, 파일명, SHA-256은 [manifest.json](manifest.json)에 기록했다. 자동 테스트로 바이트 해시를 확인한다.
- Metro의 정적 require로 앱 번들에 포함한다. 사진 서비스 인증키·종량제 호출·런타임 외부 사진 요청은 사용하지 않는다.
- 한국어 이름과 부위/도구 분류는 루핏 목록에 맞춘 값이다. 제공자의 분류를 그대로 번역한 것이 아니다. 예를 들어 랫풀다운은 루핏에서 머신, 데드리프트는 전신, 업라이트 로우는 어깨로 분류한다.
- 참고 화면의 이미지나 앱 자산을 추출하지 않았다. 현재 자산은 실사 정지 사진이며 해부학 그림/GIF가 아니다. 향후 다른 제공자로 교체할 때는 해당 이미지 이용 조건을 별도로 확인한다.

앱에서 종목 목록 하단의 사진 출처 링크로 제공자 저장소를 열 수 있다. 출처 표시와 라이선스 파일은 자산 배포 시 함께 유지한다.
