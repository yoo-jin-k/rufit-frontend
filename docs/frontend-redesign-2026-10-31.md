# 최종 디자인 적용 및 검수 기록

## 적용 기준

사용자가 제공한 최종디자인rufit-redesign.zip의 18개 화면을 기준으로 구성했습니다. 화면에 있는 예시 수치·사진·친구는 실제 사용자 데이터로 저장하지 않습니다.

| 디자인 화면 | 구현 위치 및 동작 |
| --- | --- |
| 01 로그인 | WelcomeScreen, 기존 인증 연결과 둘러보기 |
| 02–03 운동 홈 | 주간/월간 WorkoutCalendar, 날짜별 기록, 하단 고정 시작 버튼 |
| 04 운동 중 | 세트 입력·추가·완료, 운동/휴식 타이머, 종료 |
| 05 운동 완료 | MonthlyCompletion, 해당 월 날짜 수 대비 운동 일수, 오운완 진입 |
| 06 분석 | 실제 월별 운동 일수 및 최신 측정값 |
| 07–10 삼대·체중 | 날짜별 입력/수정, 선 그래프, 체중 기간 선택 |
| 11 과거 기록 | 날짜 지정, 세트별 검증, 과거 날짜 저장 |
| 12 설정 | 공통 휴식시간, 운동 기록 JSON 내보내기, 계정 진입 |
| 13–15 프로필 | 운동한 날·오운완·친구, 사진/전체 기록/달력 탭 |
| 16 오운완 | 촬영/앨범 선택, 선택적 사진과 메모, 기기 저장 |
| 17–18 친구 | 목록/검색 진입 UI 및 미연결 안내; 실제 검색·신청은 서버 작업 필요 |

## 유지보수 구조

- 공통 화면 틀: `src/components/ScreenLayout.tsx`, `AppSurface`, `BottomNavigation`.
- 색상·간격·글꼴의 공통 기준: `src/theme/tokens.ts`.
- 웹 스타일: `src/theme/web/*.module.scss`. `npm run styles`로 CSS와 토큰 SCSS를 생성합니다. 생성 파일을 직접 수정하지 않습니다.
- Expo 네이티브 스타일은 공통 토큰을 참조하는 StyleSheet를 사용합니다. Sass는 웹 전용 스타일에 사용하며 네이티브에 CSS를 강제로 적용하지 않습니다.
- 운동 상태는 WorkoutScreen의 기존 저장 훅에서 관리하므로 탭 이동으로 진행 중 운동을 초기화하지 않습니다.
- WorkoutHistory는 홈·달력·프로필의 요약/상세를 공유하고 운동 날짜 내림차순으로 표시합니다.
- 기능 진입부, 저장 규칙, 권한 요청, 타이머 적용 시점에 존댓말 설명 주석을 작성했습니다.

## 데이터와 연결 범위

기존 운동/삼대/체중 저장 형식을 유지합니다. 프로필·오운완은 `rufit.profile.v1`에 별도로 저장합니다. 운동 하나당 오운완 하나를 수정하며 사진 없는 기록도 전체 기록에서 조회합니다. 사진은 임시 파일 경로 대신 data URI로 기기에 보관하며 약 2MB 제한을 적용합니다. 저장 실패 시 기존 기록과 편집 내용을 보존하고 안내합니다.

공통 휴식시간은 기존 개인 휴식 설정의 `defaults:rest` 항목을 사용합니다. 우선순위는 종목별 개인 설정 → 공통 설정 → 종목 권장값 → 기본 90초입니다. 이미 진행 중인 휴식은 바꾸지 않습니다.

카카오·구글 실제 로그인은 개발자 콘솔 등록 및 네이티브 설정 후 시험해야 합니다. 친구 목록·검색·신청, 친구 공개, 알림은 서버/권한 연동 전입니다. 현재 오운완은 나만 보기이며 서버 사진 업로드가 아닙니다. 이용약관과 개인정보처리방침은 정식 문서 게시 전 안내입니다. 기록 내보내기는 운동 기록만 포함하고 사진·측정 기록의 전체 백업 기능은 아닙니다.

## 검수

- `npm run check`: 스타일 생성 일치, TypeScript, ESLint 및 회귀 테스트 174개.
- `npm run export`: web/iOS/Android 번들 생성. 기기 설치·스토어 배포 검증을 의미하지 않습니다.
- 별도 localhost:8101에서 검수하여 사용자 localhost:8100 기록과 분리했습니다.
- 운동 시작 → 벤치프레스 60kg/10회 → 완료 → 휴식 → 탭 전환 후 유지 → 운동 종료 → 월 달성률 확인.
- 사진 없는 오운완 저장 및 프로필 상세 메모 확인.
- 삼대 60/100/120kg 저장 후 분석 280kg 갱신 확인.
- 체중 2일 입력 후 선 그래프와 최근 날짜 값 확인.
- 과거 날짜 빈 세트 오류 안내 및 80kg/5회 유효 입력 저장, 달력 표시 확인.
- 공통 휴식시간 60초 저장 확인.
- 320×568, 390×844, 768×1024, 1280×900 화면 검수. 확인 화면에서 가로 넘침 없이 하단 메뉴 유지.
- 네이티브 카메라 촬영·사진 권한과 실기기 키보드/안전영역은 실기기 검수가 남아 있습니다.
