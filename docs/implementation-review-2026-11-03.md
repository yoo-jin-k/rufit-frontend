# 외부 참고 앱 비교 후 루핏 구현 점검

기준일 2026-11-03. 코드 확인·자동 테스트·번들 생성과 실제 기기 검증을 구분합니다.

| 우선순위 | 영역 | 확인한 상태 | 남은 작업 |
|---|---|---|---|
| 1 | 구현 목록 | 프론트·백엔드 소스 점검 | 화면/계정별 실제 동작 검수 |
| 2 | 운동 저장 | 월말 완료 안내와 반복 종료 수정, 저장 실패 재시도 회귀 추가 | 실제 서버 이전·계정 전환·목록 일치 검수 |
| 3 | 복구 | 기존 자동 저장·순차 저장·실패 상태·재실행 테스트 존재 | 실제 브라우저 종료/기기 강제 종료 검수 |
| 4 | 입력 | 복수 선택·순서·이전 세트·전체 체크 구현과 관련 테스트 존재 | 작은 화면·키보드·드래그 시각/조작 검수 |
| 5 | 휴식 | 정지/재개/복구/정지 중 조절 추가 | 모바일 백그라운드·잠금 화면·알림음 |

| 10 | 공유 | 오운완 작성과 공유 카드 출력은 별도 범위 | 사진/운동 요약 이미지 생성·저장·공유 |
| 11 | 배포 | 번들 생성 검사 | 실기기 통합 QA·테스트 배포 설정 |

## 중요한 제품 제한
- 기기 로컬 저장은 다른 기기로 자동 동기화되지 않습니다.
- 개발용 친구·응원 테스트 성공은 실회원 간 전송 성공을 뜻하지 않습니다.
- 오운완은 현재 비공개 로컬 저장입니다. 실제 사진 업로드·친구 공개·신고 처리에는 서버 기능이 필요합니다.
- 사용자는 OAuth 앱을 등록했다고 했으나 제공자·설정 확인이 남아 있습니다. 비밀키를 문서나 채팅에 기록하지 않습니다.
- 현 소스의 운동 일시정지와 휴식 일시정지는 서로 독립입니다.

## 후속 구현 순서
1. 화면·입력·종료·복구 실제 조작 검증으로 기존 기능을 마무리합니다.
2. 사회 기능의 API 계약을 먼저 정의합니다. 계정 소유권·친구 공개·차단·중복 요청·알림 목적지를 포함합니다.
3. 서버 구현과 테스트 이후 실제 프론트 연결을 진행합니다. 로컬 자료를 자동 공개하지 않습니다.
4. 성장 그래프·주간 목표·공유 카드를 추가합니다.
5. 상단 메시지 채팅과 배지는 핵심 연동 안정화 후 진행합니다.

이번 작업은 전체 프로젝트 완료를 의미하지 않습니다. 확인하지 않은 화면/기기 검증은 통과로 표시하지 않습니다.
