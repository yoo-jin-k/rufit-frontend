# 과거 날짜 운동 기록 — 2026-10-30

- 캘린더에서 오늘/과거 날짜 선택 → 이 날짜에 운동 기록 추가 → 종목·세트·무게·횟수 입력 → 기록 추가.
- 미래 날짜는 추가 버튼 미표시 및 저장 검증에서도 차단. 같은 날 여러 운동 추가 가능.
- recordDate(YYYY-MM-DD), entryMode(manual) 선택 필드 추가. 기존 기록은 startedAt의 로컬 날짜를 사용하여 하위 호환.
- 작성 시각과 운동 날짜 분리. 수동 입력은 운동시간 미측정으로 표시하며 실제 운동한 시간으로 가장하지 않는다.
- 완료 history에만 추가, current/rest/personalRest 보존. 기존 archive 순차 저장·실패 재시도 사용. 입력은 저장 버튼 전 메모리 초안이며 닫을 때 버림 확인.
- 기기 내 저장 범위. 서버 API 변경 없음.
- 전체166개 테스트·타입·린트·스타일 검사 통과, 웹/iOS/Android export 성공.
- 별도 8101 테스트 주소에서 2026-10-29 스쿼트60kg×10회 저장, 새로고침 후 날짜 표시·세트 상세 복원 확인. 사용자8100 기록에 시험 데이터 추가하지 않음.
- 네이티브 실기기 검증 미실시.

## 입력 예시 혼동 수정
- 사용자 오류 제보 확인: 10/28 벤치프레스 1·2세트 무게만 입력, 횟수는 빈 상태. placeholder 10이 실제 입력처럼 보이고 오류가 포괄적이었음.
- placeholder를 '예: 0', '예: 10'으로 명시. 미입력 필드 옆 설명과 종목/세트 번호가 포함된 검증 메시지 추가. 횟수 자동 보정 없음.
- 기존 입력값 유지한 핫리로드 확인. 이후 사용자 화면에서 10/28 완료 운동1회와 기기에 저장됨 확인.
- 타입·린트 및 관련3개 테스트 통과. 두 세트의 횟수를 차례로 입력하면 해당 누락만 안내하고 정상 저장되는 회귀 테스트 포함.
