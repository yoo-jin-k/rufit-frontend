# 운동 목록 확장 v1 준비

## 현재 반영

- 기존 18개 운동의 ID·이름·분류·이미지·기록 연결을 변경하지 않는다.
- 검색용 한글명·영문명·별칭을 목록당 한 번 정규화하는 색인을 사용한다.
- 선택 ID는 `Set`으로 확인하고 FlatList batch/window 설정을 적용한다.
- 1,000개 합성 목록에서 검색·필터·원본 순서 보존을 검사한다. 합성 목록은 테스트 전용이며 제품 운동이나 백엔드 ID가 아니다.

## 원본 수신 후 작업

1. 백엔드가 확정한 100종 이상 ID·한국어명·부위·장비·별칭 원본을 그대로 적용한다.
2. 기존 18개 identity와 새 원본의 중복·분류·반복/중량 기록 적합성을 대조한다.
3. DS-EX02가 지정한 신규 운동 대체 그래픽과 목록 UI를 적용한다.
4. 오프라인 검색/필터, 320 저높이 선택 도달, 기존 기록·입력 보존을 실제 전체 목록으로 검증한다.

현재 제품 목록 수는 여전히 18개다. 백엔드 원본과 Designer 명세가 도착하기 전에는 임의 ID, 운동명, 이미지 또는 화면 스타일을 추가하지 않는다.

Android `removeClippedSubviews`는 긴 글자·낮은 창에서 셀이 누락될 가능성이 있고 실기기 증거가 없어 적용하지 않는다. PR #46은 PR #42를 기반으로 하며 인증 PR #44와 UI QA PR #45를 포함하지 않는다. 최종 통합 체크아웃에서는 세 변경 계열을 함께 반영해 회귀를 확인해야 한다.
