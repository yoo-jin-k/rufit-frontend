# 이전 운동 기록 힌트

## 목적
운동 중 과거 무게와 횟수를 찾아보느라 화면을 이동하지 않도록 현재 종목 카드 안에서 가장 최근 완료 기록을 바로 보여준다.

## 동작
- 카탈로그 종목은 `catalogId`가 같은 가장 최근 완료 운동을 우선 찾는다.
- 직접 추가한 종목은 공백과 대소문자를 정리한 이름이 같은 기록을 찾는다.
- 이전 기록의 날짜와 세트별 `무게 × 횟수`를 종목 위에 표시한다.
- `불러오기`를 누르면 현재 종목의 세트를 이전 기록과 같은 개수·값으로 교체하되 모두 미완료 상태로 만든다.
- 현재 운동에 있던 다른 종목과 과거 기록 원본은 변경하지 않는다.
- 이전 기록을 불러오면서 현재 종목의 세트가 바뀌면 그 종목에 걸려 있던 휴식 타이머는 제거한다.
- 한 운동 최대 300세트 제한과 저장된 수치 검증을 그대로 적용한다.

## 현재 범위
이 기능은 로컬 완료 이력을 기준으로 한다. 서버 계정의 다른 기기 기록을 같은 힌트에 합치는 것은 서버 동기화 UI가 정리된 뒤 연결한다.
