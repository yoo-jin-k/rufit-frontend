# 종목별 휴식시간

- 로컬 기록 화면은 종목별 권장시간을 표시하고 0~3600초의 개인시간 저장, 권장 사용 복귀를 제공한다. 개인값은 같은 종목의 다음 운동에도 유지된다.
- 세트 완료와 휴식 대상/절대 종료시각을 같은 저장본에 기록한다. 다시 열어도 휴식은 다시 시작하지 않는다. 이미 완료한 세트를 재완료하거나 개인 설정을 변경해도 현재 휴식은 유지한다.
- 대상 세트 완료 취소/삭제, 운동 종료/교체는 휴식을 해제한다. 다른 세트 삭제·복제는 대상 ID를 바꾸지 않는다.
- 운동시간 정지는 휴식시간을 멈추지 않는다. 휴식은 ±10초 조절/닫기가 가능하며 조절 시 현재부터0~3600초 범위로 제한한다.
- 로컬 archive v1/v2를 읽어 v3으로 저장한다. 예전 입력/정지 상태는 보존하고 잘못된 휴식/개인 설정을 빈 데이터로 덮어쓰지 않는다.
- 카탈로그 초기값은 백엔드 V23과 동일하며 통합시험에서 전18종을 대조한다. [추천값 근거와 서버 계약](https://github.com/yoo-jin-k/rufit-backend/blob/feature/exercise-rest/docs/exercise-rest.md)을 따른다. 짐워크 각 종목의 실제 추천 숫자는 미확인이다.
- 현재 화면은 기기 저장 모드다. 서버용 typed 조회/수정 및 완료 자동 적용 API도 시험했으나 개인설정 자동동기화 화면은 후속이다. 기기에서 직접 등록한 종목의 기본값은90초이며 서버 계정기본값 설정은 별도다.

검증: 추천 차이, 개인0초/복귀, 완료·타이머 원자적저장, 재시작, 설정변경 중 타이머 유지, 대상삭제, 정지와 휴식독립성, ±10초/범위, 이전자료·손상자료를 검사한다.
