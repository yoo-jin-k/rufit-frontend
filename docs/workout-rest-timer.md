# 운동 화면과 휴식 타이머

- 운동 시간과 종료 버튼은 상단, 종목 추가와 휴식 조작부는 하단에 고정합니다.
- 세트를 새로 완료하면 해당 종목의 휴식이 시작됩니다. 완료 취소, 삭제, 운동 종료 시 기존 연결 규칙을 유지합니다.
- 하단의 ± 버튼은 남은 시간을 10초씩 조절합니다. ×는 현재 휴식만 종료합니다.
- 시간 선택 창은 적용 전까지 저장하지 않습니다. 이 종목만 적용은 다른 종목에 영향을 주지 않습니다.
- 모든 종목에 적용은 기존 개인 예외를 해제하고 이후 추가하는 종목에도 적용합니다. 권장값 전체 적용은 각 종목 기본값으로 복귀합니다.
- 진행 중인 대상 휴식은 적용한 시간으로 다시 시작합니다. 0초는 해당 종목 자동 휴식을 끕니다.
- 운동 및 설정은 현재 기기에 저장됩니다.

## 기본값 근거와 한계

휴식은 종목명만으로 결정되지 않으며 목표·강도·훈련 경험에 따라 달라집니다. 다음 자료를 바탕으로 앱의 조절 가능한 초기값을 정했습니다. 종목별 임상 검증값이 아닙니다.

- NSCA: 복합 운동과 보조·단일관절 운동의 휴식 차이, 보조 운동 1~2분 범위.
  https://www.nsca.com/contentassets/fb8a7be6eb174934bb8844703c4de4cc/ptq-10.1.3-how-to-manipulate-rest-intervals-to-maixmize-strength-training-effectiveness.pdf
- ACE: 근력 목표의 고강도 운동은 2~5분 등 목적에 따른 차이.
  https://www.acefitness.org/resources/pros/expert-articles/4954/how-to-select-the-right-rest-intervals-and-post-training-recovery-for-your-clients/

기존 카탈로그의 지정값을 우선합니다. 미지정 종목은 큰 복합운동 180초, 일반 복합운동 120초, 보조 운동 90초를 사용합니다. 분류는 recommendedRest.ts에서 관리하며 사용자 설정이 우선합니다. 카탈로그 API 원본은 변경하지 않습니다.
