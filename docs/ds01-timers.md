## 검증
- `npm run check`: 스타일 생성물 일치, 타입, 린트, 122개 테스트 통과.
- `npm run export`: iOS/Android/Web 번들 생성 통과.
- 실제 Chrome: 320×568, 375×667, 390×844, 430×932, 768×1024, 1024×768, 844×390에서 가로 넘침 없음. 크기 변경 중 입력값·입력 DOM 포커스·저장 원문 유지, 새로고침 후 복구.
- 실제 Chrome: 버튼 기본/보조/눌림 색상, 48px 최소 높이, 긴 문구 줄바꿈, disabled/loading 클릭 차단, 로딩 전후 폭 유지, aria-busy, 2px 포커스 외곽선.
- 실제 Chrome: 휴식 종료·최대 경계, 종료 후 +10초 재개, 일시정지한 운동 및 개인 휴식 설정 불변, 긴 운동명/123시간 표시.
- 회귀 테스트는 실제 Button과 RNW 렌더러로 busy 전달을 검사한다. aria-busy를 제거하면 실패하고 복구하면 통과함을 확인했다.
- 화면/측정 자료: `docs/verification/ds01-timers/`. 버튼 상태 이미지는 실제 컴포넌트를 임시 독립 화면에 렌더링한 결과다. 제품에 검증용 화면을 추가하지 않았다.

## 남은 범위
- SetRow·LocalSaveStatus·RestSetting v1.1 및 나머지 화면 타이포그래피는 후속 작업이다. 이번 PR을 전체 DS-01 완료로 보지 않는다.
- 글자 배율 1.3/2.0의 배치 계산은 단위 테스트로 확인했다. RNW는 네이티브 글자 배율을 재현하지 않으므로 실제 기기 글자 확대 검증으로 간주하지 않는다.
- iOS/Android 실제 기기의 글자 확대·키보드·safe area·VoiceOver/TalkBack 검증은 미실시다. 플랫폼 번들 생성 성공과 실기기 검증을 구분한다.
- 기존 사용자 미리보기 8081/8093과 기기 저장 자료는 수정하지 않았다. 검증은 독립 Chrome 저장소/8097·8098을 사용했다.
