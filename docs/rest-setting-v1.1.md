# DS-01 RestSetting v1.1

## 변경
- developer에서 만든 `codex/ds01-rest-setting`에 선행 PR39/ae2298a를 연결했다. 이번 단위 비교 기준은ae2298a다.
- 기존 종목 카드 안의 펼침/접힘 흐름과 name/seconds/source/recommended/finished/onSave 계약을 유지했다.
- 접힌 버튼은 적용값만 표시하고 접근성 이름에 종목을 포함한다. 개인 설정은 다음 세트 적용 안내,종료 운동은 읽기전용 텍스트다.
- 펼치면 ‘휴식시간 (초)’ 라벨 → 입력 → 필드 오류 → 범위/현재휴식 유지 안내 → 저장/권장·기본복귀/취소 순서로 표시한다.
- 기존 세트 입력 스타일을 값 변경 없이 SetInput.styles.ts로 옮겨 공동 사용한다. 최소48/radius12/16·24,초점·오류 색상도 동일하다. 신규 토큰값은 없다.
- 펼칠 때만 적용값으로 초안을 초기화한다. 입력 도중 화면 크기나 저장 상태가 변해도 문자열·커서·오류를 덮어쓰지 않는다.
- 빈 값/음수/소수/문자/3600 초과를 저장 시 거부한다. 유효한0~3600만 onSave에 전달하고 null은 개인값 제거를 유지한다.
- 오류는 입력 바로 아래,첫 오류 입력에 포커스. 키 입력마다 알리지 않고 오류 전이만 알린다. iOS 실제 낭독은 미검증이다.
- 적용 후 접혀도 디스크 저장 성공을 주장하지 않는다. 기기 쓰기/재시도는 기존 LocalSaveStatus가 담당한다.

## 증거와 한계
- docs/verification/rest-setting/browser-results.json 및 PNG,브라우저 검사 원문 보관본 포함. 모든 기록은 독립 브라우저 테스트 데이터다.
- editing-390/1024 이미지는 잘못된 값 제출 뒤125로 고친 상태다. 명세대로 재제출 전까지 이전 오류가 유지되며125를 범위 오류로 새 판정한 것이 아니다.
- applied-save-error 이미지는 상단 실패 상태의 가시 영역이다. 적용값·현재휴식 보존은 JSON에 기록한 동작 검사로 확인했다.
- 실제 iOS/Android 키보드 첫 탭/안전영역/글자배율1.3·2.0/VoiceOver·TalkBack는 미검증이다. 브라우저 크기 변경을 실제 기기 접기·회전 검증으로 확대하지 않는다.
- API·저장소·운동/휴식 도메인 변경 없음. 사용자의 기존8081/8093미리보기나 저장자료를 수정하지 않았다.
