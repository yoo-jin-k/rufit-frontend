# 개발 기준

| 순서 | 브랜치 | 완료 기준 |
|---|---|---|
| 0 | feature/project-setup | Expo/TypeScript 구조, 타입·lint·번들 검증, develop PR |
| 1 | feature/workout-record | 운동 시작, 종목 추가, 무게·횟수 입력, 종료 |
| 2 | feature/routine | 루틴 작성 및 루틴으로 운동 시작 |
| 3 | feature/history | 완료 기록 목록·상세 재조회 |
| 4 | feature/sets-rest | 세트 완료·수정, 휴식 타이머, 백그라운드 시간 보정 |
| 5 | feature/save-recovery | 로컬 자동저장, 재실행 복구, 저장 실패 처리 |

각 기능은 화면과 도메인 로직, 검증을 함께 작성한다. 서버 미연결 상태를 서버 저장 완료로 표현하지 않는다.
백엔드는 별도 저장소에 구성하고 API 계약으로 연결한다. 현재 초기 구조에는 인증·서버·영구저장이 없다.
후속 기능이 앞 PR에 의존하면 해당 기능 브랜치에서 분기하고 의존성을 PR에 명시한다. PR 병합은 별도 승인 전 자동으로 하지 않는다.
실기기 검증에서는 키보드에 입력칸이 가려지는지, 큰 글씨, 안전 영역, 앱 재시작을 확인한다.
# 기본 휴식 설정 API

검증된 계정 세션의 `api.restPreferences()`로 기본 휴식 초와 버전을 조회하고, `api.saveRestPreferences(version, seconds)`로 저장합니다. 최초 기본값은 90초/버전 0이며 0~3600초 정수만 허용합니다. 다른 기기에서 먼저 저장한 경우 409를 받고 다시 조회합니다. 응답 유실 시에도 조회로 결과를 확인합니다.

세트 완료 시 선택한 휴식 시간을 기존 `completeSet`의 명시적인 인자로 전달합니다. 설정 변경만으로 이미 시작한 휴식은 바뀌지 않습니다. 이 통신 기능은 실제 서버로 검증하며 설정 화면과 기존 로컬 운동 화면의 연결은 아직 하지 않았습니다.
