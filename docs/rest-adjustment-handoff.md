# FE-01 휴식 조절 인계

2026-09-13 · 기존 `feature/rest-timer-adjustment` 인수 마감.

## 변경

- 만료된 휴식에 +10초를 누르면 현재부터 10초를 계산한다. 기존 0~3600초 제한과 휴식 대상, 세트 입력, 운동 정지 상태를 유지한다.
- API `adjustRest(id, version, seconds)`는 한 번만 전송한다. 응답 유실/409 이후 호출자는 `workout(id)`로 먼저 조회한다. 최신 버전을 받은 뒤 새로운 사용자 조작에만 별도 변경 요청을 보낸다.
- 로컬 재저장은 계산된 저장본을 다시 쓴다. 휴식 조절을 다시 실행하지 않는다.
- 인수한 운동/저장/타이머의 한국어 기능 주석을 보존·보완했다.

API 원본: [백엔드 휴식 조절 계약](../../rufit-backend/docs/api-contracts/rest-adjustment.md). 계약을 이 문서에서 별도로 재정의하지 않는다.
