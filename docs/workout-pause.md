# 운동시간 정지·진행

- 기기 저장 화면에서 운동 정지/운동 진행을 명시적으로 누른다. 정지 중 입력도 보존한다.
- 현재 시각과 시작·정지·누적 정지 시각의 차이로 표시한다. 화면 타이머는 다시 그리기만 하며 매초 저장하지 않는다. AppState는 표시 갱신만 하므로 앱을 닫아도 자동 정지되지 않는다.
- 정지 상태를 기기에 저장한 뒤 다시 열면 계속 정지 상태다. 진행을 눌러야 재개한다. 저장 실패는 기존 상태 메시지와 재시도 버튼으로 알린다.
- 정지 중 종료하면 마지막 정지 구간도 제외한다. 완료 기록 화면도 같은 계산을 사용한다.
- 로컬 저장 키는 유지하고 archive schemaVersion 1을 읽어 2로 저장한다. 과거 기록을 지우지 않는다. 이해하지 못하는 형식이나 잘못된 시각은 덮어쓰지 않는다.
- 연결 저장소 형식은 1/2를 읽어 3으로 저장한다. 서버의 정지 정보를 복구하고, 일반 입력 수정으로 타이머를 변경하는 것은 거부한다. 충돌에서 로컬 입력을 선택해도 서버의 정지 시각은 유지한다.
- typed API에 pause/resume을 추가했다. 전용 계정 화면 요청 조율과 실제 로그인 연결은 후속 작업이다. 현재 앱 화면의 기록은 기기에 저장된다.

검증: 재시작을 새 저장소 인스턴스로 재현해 12시간 경과/정지/재개/반복/종료/이전 형식/잘못된 시각을 검사한다. signed OIDC와 실제 PostgreSQL HTTP 통합은 서버 상태·소유권·버전·휴식 독립성을 확인한다.
