# 로컬 휴식 타이머

## 목적
세트를 완료하면 사용자가 별도 화면을 열지 않아도 바로 다음 세트를 위한 휴식 시간을 볼 수 있게 한다. 서버 연결 전 내부 실행본에서도 앱 재시작 뒤 같은 휴식 상태를 복구한다.

## 동작
- 유효한 세트를 완료하면 기본 1분 30초 휴식이 시작된다.
- 남은 시간은 저장된 시작 시각과 지속 시간으로 계산하므로 화면 전환이나 앱 재실행 동안 별도 카운터를 누적하지 않는다.
- 사용자는 30초씩 연장하거나 즉시 건너뛸 수 있다.
- 시간이 0이 되어도 사용자가 확인할 수 있도록 타이머 카드는 남고, 닫기를 누르면 제거된다.
- 완료를 취소하거나 해당 세트를 삭제하면 그 세트의 휴식 타이머도 제거된다.
- 운동 종료 시 휴식 타이머는 종료 기록에 남기지 않는다.
- 휴식 지속 시간은 최대 30분으로 제한한다.

## 저장·복구
`Workout.restTimer`에 `setId`, `startedAt`, `durationMs`를 저장한다. 기존 로컬 저장 스키마에 선택 필드로 추가해 이전 기록은 그대로 읽는다. 복구 시 대상 세트가 존재하고 완료 상태인지, 시각과 지속 시간이 안전 범위인지 검증한다.

## 범위
이 변경은 로컬 운동 화면의 사용성을 위한 것이다. 계정 연결 운동의 서버 휴식 상태(`restSetIndex`, `restEndsAt`) 계약은 변경하지 않는다. 두 흐름의 UI 통합과 푸시·소리·진동은 별도 검증 대상으로 남긴다.

## 검증 기준
- 세트 완료 → 90초 시작
- 시간 경과에 따른 남은 시간 계산
- 30초 연장과 건너뛰기
- 완료 취소·세트 삭제·운동 종료 시 정리
- 저장 후 다시 읽어 같은 타이머 복구
- 손상된 타이머 데이터 거부
- 기존 타입 검사·린트·단위 테스트·Expo 의존성 검사·iOS/Android/Web export에 회귀 없음
