| test-3 | 벤치도윤 |

현재 사용자는 기본적으로 나 (테스트)입니다. 상대에게 신청한 후 목록 하단의 사용자 전환 도구를 펼쳐 상대 사용자로 전환하면 받은 신청을 수락·거절할 수 있습니다. 신청자는 신청을 취소할 수 있습니다. 실제 로그인 전환이 아니며 테스트 관계만 전용 저장 키 `rufit.test.friends.v1`에 보관합니다. 실제 프로필·운동·사진·인증 데이터는 읽거나 수정하지 않습니다.

이 화면은 __DEV__에서만 제공하며 정식 배포 및 TestFlight 배포 빌드에는 활성화되지 않습니다. 서버 계정 생성이나 기기 간 친구 연결을 구현한 것이 아닙니다. 서버 연동 전 친구 UX를 점검하기 위한 로컬 데이터입니다.

검증: 전체 검사 177개 통과. 실제 개발 화면에서 신청 → 상대 전환 → 받은 신청 확인 → 거절을 확인했습니다. 수락·권한 제한·중복 신청·재신청·직렬화 및 손상 데이터 거부는 모델 회귀 테스트로 확인했습니다.

## 앱 안 알림

운동·분석·프로필·설정 및 공통 제목이 있는 상세 화면의 오른쪽 위에 알림을 표시합니다. 프로필에서는 오운완 추가 버튼 오른쪽에 있습니다. 나(테스트)에게 온 미처리 친구 신청이 있으면 빨간 점이 표시됩니다. 알림을 여는 것만으로 신청을 처리하지 않으며 수락·거절하면 해당 항목과 빨간 점이 갱신됩니다. 친구 화면의 상대 사용자 전환과 무관하게 알림 수신자는 나(테스트)로 고정됩니다.

친구 화면과 알림은 공통 저장 상태를 구독하여 저장 성공 후 동시에 갱신됩니다. 앱 외부 푸시 알림이나 서버 알림 기능은 아닙니다. 정식 빌드에서는 로컬 테스트 친구 데이터를 읽지 않습니다.

검증: 전체 검사 177개 통과. 네 개 메뉴의 받은 신청 1개 표시, 프로필 추가 버튼 오른쪽 빨간 점, 알림을 눌렀을 때 스쿼트서연의 신청 표시 확인. 사용자가 직접 수락할 수 있도록 기존 신청은 미처리 상태로 유지했습니다.

## 친구 관리 메뉴와 알림 레이아웃 (2026-11-01)

- 알림 제목 옆의 전체 너비 버튼 때문에 제목이 줄바꿈되던 문제를 수정했습니다. 제목에 줄 높이를 지정하고 닫기 버튼을 스크롤 밖 하단에 고정했습니다.
- 신청 알림 카드 우측 상단과 모든 친구 목록 행 우측에 공통 세로 점 세 개 메뉴를 배치했습니다. 친구인 상대는 친구 해제 버튼을 메뉴 왼쪽에 표시합니다.
- 차단은 확인 후 양쪽 친구 관계·대기 신청을 제거하고 양방향 재신청을 막습니다. 본인이 차단한 행은 차단됨으로 표시하며 메뉴에서 해제할 수 있습니다. 상대가 차단한 사용자는 목록에 표시하지 않습니다. 차단 해제는 이전 친구 관계를 복구하지 않습니다.
- 친구 해제는 확인 후 연결만 해제하며 다시 신청할 수 있습니다. 신고는 사유 선택이 필수이며 같은 사유의 중복 신고는 추가 저장하지 않습니다. 신고 자체는 친구 관계를 바꾸지 않습니다.
- 신고는 운영자에게 전송되지 않는 로컬 테스트 저장입니다. 실제 서버 차단·신고 API 및 운영 대응은 별도 구현이 필요합니다.
- 관계·차단·신고를 `rufit.test.friends.v2`에 한 번에 저장합니다. v2가 없는 경우에만 기존 v1을 읽습니다. 저장 실패 시 메모리 상태를 변경하지 않고 기존 자료를 유지합니다.
- 검증: 전체 검사 180개 통과. 알림 제목·하단 닫기, 카드 메뉴·신고 사유 화면, 친구 해제 확인 화면, 320px 목록 가로 넘침 없음 확인. 기존 민준 친구 관계와 서연의 미처리 신청은 유지했습니다.

## 가상 프로필·공통 친구 행·하트 (2026-11-01)

- 친구 목록과 알림은 FriendRow를 공유합니다. 34px 사진, 작은 닉네임·버튼·더보기 아이콘을 사용하고 수락·거절을 가로로 배치합니다. 버튼 시각 크기는 줄이고 터치 높이 44px를 유지합니다.
- 사진·닉네임에서 상대 프로필로 진입합니다. 가상 유저 5명은 각각 프로필 사진과 오운완 3개, 대응 운동 기록 3개를 가집니다. 오운완·전체 기록·달력 탭, 게시물 상세를 확인할 수 있습니다. 사진 및 기록은 샘플이며 실제 사용자의 운동 보관함에는 넣지 않습니다.
- 내 오운완 사진 아래, 사진 없는 오운완의 기록 상세, 가상 프로필의 게시물 목록·상세에 하트를 제공합니다. 다시 누르면 취소하며 `rufit.local.post-likes.v1`에 사용자·게시물 쌍으로 저장합니다. 목록·상세는 같은 저장 상태를 구독하고 저장 실패 시 상태를 갱신하지 않습니다. 가상 게시물 ID와 실제 기기 기록 ID는 test:/own: 접두사로 분리합니다.
- 상대 프로필도 현재 차단 상태를 구독하여 차단 관계에서는 게시물을 표시하지 않습니다. 가상 프로필은 테스트 목적의 공개 예시이며 실제 회원의 공개 범위 정책을 확정한 것이 아닙니다.
- 합성 사진 원본 및 전체 프롬프트: assets/test-social/README.md. 내장 이미지 생성 도구로 만든 3×3 아틀라스를 앱에서 셀별로 표시합니다. 외부 사진 URL이나 실제 회원 사진을 사용하지 않습니다.
- 검증: 검사 183개 통과, 웹·iOS·Android 번들 생성 성공. 320px 친구 목록·알림·프로필 화면, 알림 사진에서 상대 프로필 진입, 전체 기록·달력, 하트 저장·재접속 유지·취소 및 목록/상세 동기화 확인. 검수용 하트는 취소했고 기존 친구·신청은 유지했습니다.
- 사진·게시물·하트는 현재 기기 기반 테스트입니다. 서버 업로드·다른 기기와의 좋아요 집계 및 실기기 사진 렌더링 검증은 포함하지 않습니다.
