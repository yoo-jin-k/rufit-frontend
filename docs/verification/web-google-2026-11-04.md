# 로컬 웹 Google 로그인 검증 — 2026-11-04

## 실제 확인 결과
- Rufit 전용 Google 프로젝트의 웹 OAuth JSON에서 등록된 HTTPS callback을 확인하고 별도 로그인 시험 서버에 적용했습니다. 비밀값은 private/google.env에만 저장했습니다.
- 사용자가 Chrome에서 계정을 선택하고 동의한 후 루핏의 Google 계정 로그인 완료 화면을 확인했습니다.
- 새로고침 후 설정의 계정 연결됨 및 계정 관리의 Google 로그인 상태를 확인했습니다. 기존 인증 조정자는 갱신 및 /me 확인 후에만 이 상태를 표시합니다.
- 로그아웃을 실행하여 서버 종료 확인 메시지를 확인했습니다. 새로고침 후 로그인 시작 화면으로 돌아왔습니다.
- 사용자 운동, 사진, 친구 기록은 수정하지 않았습니다. 실제 계정은 분리된 로그인 시험 DB에 연결됩니다.

## 범위와 제한
- Chrome localhost:8100의 실제 계정 시험입니다. 운영 배포와 iOS/Android 실기기 검증 결과가 아닙니다.
- 갱신 정보는 sessionStorage에 보관하며 같은 탭 새로고침에 사용합니다. 운영용 장기 로그인은 별도 보안 쿠키 설계가 필요합니다.
- 구글 키의 Bitwarden 백업은 아직 수행하지 않았습니다. 키 파일을 Git이나 문서에 포함하지 않았습니다.
- 이번 검증에는 코드 변경이 없으며 이전 프론트 243개/서버 설정 4개 자동 테스트 결과와 실제 계정 UI 확인을 구분합니다.
