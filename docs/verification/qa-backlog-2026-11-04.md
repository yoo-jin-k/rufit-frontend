# 검수 우선순위와 코드 정리

## 검수 실행 순서
| 순서 | 위험/검수 | 자동 검증 | 실제 화면/기기 검증 |
|---|---|---|---|
| 1 | 계정 전환 후 이전 계정 응답·게시물 소유권·동시 응원 중복·삭제 버전 충돌 | 기존 테스트 + 동시 요청 추가 | 실제 로그인 복원 완료, 두 계정 자료분리 추가 필요 |
| 2 | 친구 수락→운동 공개→응원→알림→프로필, 게시물 공유→좋아요→알림 | 개별 서비스·화면 테스트 존재 | 두 계정 전체 연결 흐름 미완료 |
| 3 | 사진 선택 실패·사진 개수/형식·게시물 편집 충돌·삭제 재시도 | 실패/재시도·파일 정규화 존재, 충돌 초안·조회 실패 회귀 테스트 추가 | 실기기 사진 권한/촬영/첨부 미완료 |
| 4 | 작은 화면·긴 닉네임·키보드·화면읽기·고정 버튼 겹침 | 타입·접근성 일부 존재 | 현재 웹 폭 482px에서 홈·프로필·달력 확인, 320px/키보드 추가 확인 필요 |
| 5 | 화면 잠금·백그라운드·네트워크 복귀·휴식 알림 | 상태 전환 훅/타이머 테스트 존재 | iOS/Android 실기기 미완료 |

자동 검증 통과를 실제 계정·실기기 검수 완료로 대신하지 않습니다. 실사용 계정에서 사진/친구/운동 시험 자료를 임의 생성·삭제하지 않습니다.

## 코드 정리 범위
최근 소셜 기능(친구·알림·게시물·응원)과 공통 사진 선택 코드의 형식을 통일하고,소유권·동시성·재시도·실패 보존 주석을 보완합니다. 기존 기능과 저장 형식은 유지합니다.
프로젝트 저장소의 외부 서비스명은 문서와 주석에서도 제거합니다. 별도 조사 자료와 읽기 전용 sources는 수정하지 않습니다.

## DB 주석 정리
V23의 실행SQL은 동일합니다. 설명 주석 변경에 따른 체크섬 호환은 알려진 기존 체크섬과 버전/파일명/성공 여부가 모두 일치할 때만 적용합니다. 데이터 재생성,전체 repair,검증 비활성화는 하지 않습니다.


## 이번 실행 결과
- 백엔드: 테스트 234개 통과, 실패/오류/건너뜀 0개, 패키징 성공. 로컬 로그인 시험 서버 반영 후 health UP 확인. 전용 테스트 DB에서 실행했습니다.
- 프론트: 테스트 256개 통과, 실패/건너뜀 0개. 스타일 생성 일치, 타입 검사, 린트 통과(린트 경고 0개). 웹 배포용 내보내기 성공.
- 추가 회귀 검증: 동시 응원 12회 요청에서도 응원/알림 각 1건, 편집 충돌 시 초안 유지 및 중복 저장 차단, 게시물 조회 실패 시 로딩 종료와 재시도 복구.
- 실제 웹에서 발견한 오운완 수 무한 ‘확인 중’ 표시를 ‘확인 실패’로 구분했습니다. 닉네임 미등록 시 해결 방법을 안내합니다. 오류를 게시물 0개로 처리하지 않습니다.
- 현재 폭에서 하단 메뉴와 버튼, 프로필 사진/숫자/탭, 달력 전환을 확인했습니다. 실제 계정의 친구 관계와 운동 자료는 수정하지 않았습니다.
- 기능별 주석은 권한, 동시 요청, 버전 충돌, 재시도와 실패 보존을 중심으로 보완했습니다. 모든 줄에 설명을 반복해서 달지는 않았습니다.

## 원격 저장소 정리 범위
- 프론트 46개, 백엔드 9개 브랜치의 현재 파일에서 대상 외부 서비스명을 제거했습니다. 반영 후 원격 커밋 해시를 검증했습니다.
- 기존 커밋에 정리 커밋을 추가했으며, 과거 커밋·PR의 이전 diff·캐시·다른 복제본은 지우지 않았습니다. 현재 파일 정리와 전체 이력 삭제는 다릅니다.
- DB 마이그레이션은 실행 SQL이 동일한지 확인하고, 알려진 이전 주석 체크섬만 호환하도록 콜백을 추가했습니다.

## 다음 검수 순서와 완료 조건
1. 두 전용 실제 로그인 시험 계정에 닉네임을 등록한 뒤 친구 수락 → 운동 공개 → 응원 → 알림 → 프로필 → 게시물 좋아요 이동을 각각 양쪽 화면에서 확인합니다. 현재 계정은 닉네임 미등록이며 전체 연결 흐름은 미검증입니다.
2. 실기기 카메라/사진 권한 거부·재허용, 여러 장 첨부, 업로드 중 연결 끊김, 편집 내용 보존을 확인합니다.
3. 320/375px 모바일 폭, 긴 닉네임, 키보드를 띄운 입력 화면, 화면읽기 순서와 터치 영역을 확인합니다. 현재 482px 화면 확인만으로 전 기기 검수를 완료 처리하지 않습니다.
4. iOS/Android에서 잠금·백그라운드·네트워크 복귀 후 휴식/세트 타이머와 알림을 확인합니다.

실기기 및 두 계정 검수가 남아 있으므로 전체 출시 QA 완료 상태가 아닙니다.
