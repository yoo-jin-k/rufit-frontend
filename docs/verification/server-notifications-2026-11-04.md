# 서버 친구 알림 연동 — 2026-11-04

## 완료
- 로그인한 계정의 알림 버튼은 서버 알림함을 사용합니다. 게스트의 로컬 시연 알림은 별도 유지합니다.
- 공통 Provider가 모든 메뉴의 읽지 않은 알림 수와 빨간 점을 공유합니다. 활성 앱에서 30초 간격, 앱 복귀, 알림 열기, 작업 후에 갱신합니다.
- 친구 신청/수락 이벤트를 서버에 저장합니다. 기존 대기 신청도 마이그레이션으로 반영합니다.
- 알림 안에서 수락·거절·차단·신고, 닉네임을 눌러 상대 공개 프로필 열기가 가능합니다.
- 목록을 보는 것만으로 읽음 처리하지 않습니다. 알림 클릭 시 서버에 읽음 처리하고 신청 응답 시 원래 신청 알림은 사라집니다.
- 긴 목록은 30개씩 조회하며 닫기 버튼은 하단 고정 영역에 둡니다. 공통 색상·간격·반응형 레이아웃을 재사용합니다.
- 계정 변경 시 알림을 초기화하고 오래된 조회 결과가 최신 결과를 덮어쓰지 않도록 요청 순서를 확인합니다.

## 검증
- 프론트 전체 `npm run check`: 스타일 생성·타입 검사 통과, 246개 테스트 통과. 최종 lint 오류 0 / 기존 경고 3개.
- 백엔드 전체 `mvn -q test package`: 전용 rufit_test DB에서 224개 테스트 통과, 빌드 성공.
- 화면 자동 검증: 목록 열기만으로 읽음 처리하지 않음, 프로필 대상 연결, 읽음, 수락 후 목록 반영, 다른 계정에 이전 알림 미노출.
- 서버 검증: 중복 이벤트 방지, 읽음 소유권, 취소·거절·차단·해제·재친구 시 오래된 알림 제거, 커서 페이지 중복 방지, 미인증 접근 차단.
- 로컬 로그인 서버에 반영 후 health 200/UP, 미인증 알림 조회 401 확인. 사용자 친구 관계/운동 기록은 테스트로 변경하지 않았습니다.
- 실제 두 계정의 브라우저 간 알림 수신 및 iOS/Android 실기기 시각 검수는 이번에 수행하지 않았습니다.

## 남은 의존 기능
- 좋아요 알림: 서버 오운완 게시물/사진 저장, 공개 범위, 좋아요 API와 게시물 이동 연결이 선행되어야 합니다.
- 응원 알림: 서버 운동 중 상태 공유와 친구 응원 이벤트 저장이 선행되어야 합니다.
- 현재 알림은 앱 안에서 조회하는 방식입니다. 앱이 종료된 상태의 OS 푸시는 별도 작업입니다.
- 서버 프로필 사진 API가 없으므로 임의 테스트 사진 대신 공통 프로필 아이콘을 사용합니다.
