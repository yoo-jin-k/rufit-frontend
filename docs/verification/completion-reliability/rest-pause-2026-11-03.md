# 휴식 일시정지와 복구

- 기본/권장 휴식시간과 현재 남은 시간을 분리하여 유지합니다.
- 정지 시각을 로컬 저장본에 넣고 재개 시 남은 시간을 새로운 종료 시각으로 옮깁니다. 운동 경과 시간은 멈추지 않습니다.
- 정지 중 ±10초는 고정된 남은 시간에 적용합니다. 설정 적용은 선택한 시간으로 다시 시작합니다.
- 운동 완료 또는 휴식 종료 시 정지 상태도 함께 제거합니다.
- 하단 조작은 RestTimerDock으로 분리하고 좁은 화면은 줄바꿈을 허용합니다. 공통 디자인 토큰을 사용합니다.
- Node24.18.1: npm run check 통과, 자동 테스트226개. 기존 린트 경고2개.
- 변경 전후 데이터 복구·시간 경계·접근성 이름·만료 버튼 상태를 검증했습니다.
- iOS/Android/Web export는 컴포넌트 분리 전 성공했습니다. 최종 분리 후 타입·린트·테스트를 다시 통과했습니다.
- 실제 화면 크기별 시각 검수, 휴대폰 잠금 화면·알림음·OS 백그라운드 동작은 미검증입니다.
