# 오운완 사진 오류 복구 검증

- 사진 읽기 실패 시 기존 사진과 글을 보존하며 저장을 잠시 막습니다.
- 사용자가 '실패한 사진 추가 건너뛰기'를 선택하면 기존 사진/글로 저장할 수 있습니다. 실패한 사진을 조용히 누락시키지 않습니다.
- 사진 개수 초과·읽기 실패 안내와 주석을 정중한 한국어로 정리했습니다.
- 실제 JournalComposer와 React Native Web 렌더러로 사진 읽기 실패→건너뛰기→저장을 검증했습니다. 기존 사진/글이 보존됐습니다.
- 최종 npm run check: 테스트227개 통과, 스타일·타입·린트 검사 통과(기존 import 위치 경고2개).
- 최종 npm run export: iOS/Android/Web 번들 생성 성공.
- 실제 모바일 카메라 권한, 앱 잠금/백그라운드, 전 화면 시각 검수는 아직 수행하지 않았습니다.
