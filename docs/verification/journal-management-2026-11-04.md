# 계정 게시물 편집·삭제

- 프로필의 내 계정 오운완 상세에 게시물 편집/삭제를 추가했습니다.
- 다른 기기에서도 서버 저장본의 글200자,사진0~5장,사진 순서,나만 보기/친구 공개를 편집할 수 있습니다. 날짜와 운동 요약은 유지합니다.
- 사진 선택 규칙은 기존 작성 화면과 공통 함수로 분리했습니다. 실제 카메라/앨범 동작은 실기기 검수가 남습니다.
- 저장 실패는 초안을 유지하며,다른 곳에서 수정된409는 덮어쓰지 않습니다. 닫기에서 초안 버리기를 확인하고 재조회합니다.
- 계정 게시물 삭제는 복구 불가/원래 운동과 기기 오운완 유지 문구를 먼저 보여줍니다. 확인 전 요청을 보내지 않으며 실패 시 화면을 유지합니다.
- 서버는 소유자/최신버전을 확인하고 사진·좋아요·알림을 함께 제거합니다. 반복 삭제는204,삭제 후 오래된 편집은409입니다.

## 검증
- FE254개 테스트 및 타입·스타일·린트 검사 통과(기존 경고3).
- BE233개 테스트 통과,독립rufit_test PostgreSQL에서 수행했습니다. 실제 사용자 데이터 삭제는 수행하지 않았습니다.
- 화면 컴포넌트의 삭제 취소/실패/재시도,편집 시 날짜·요약 보존과 사진 삭제·공개 변경 후 저장 재시도를 검증했습니다.
- 전체 테스트에서 드러난 Node의 Expo 카메라 모듈 로딩 제한은 테스트 도우미에서 기기 경계만 분리했습니다. 실제 촬영이 검증되었다고 간주하지 않습니다.
- 실제 두 계정 UI 검증은 카카오·구글 콘솔의 새 리다이렉트 URI 등록 이후 진행합니다.

## 로그인 연결 복구
기존 외부 임시 터널은 서버 로그에서 Unauthorized: Tunnel not found로 확인했습니다.
같은 API로 새 터널을 만들고 로컬 설정을 갱신했습니다. 사용자에게 제공자 콘솔 등록 절차를 안내했습니다.
고정 도메인 도입 전 임시 주소는 다시 바뀔 수 있으며,운영 배포는 이번 범위가 아닙니다.

## 새 주소 로그인 재검증
- 사용자가 카카오·구글 리다이렉트 URI 추가 후 실제 웹 검증을 수행했습니다.
- 카카오 로그인 성공·앱 복귀·로그아웃 완료를 화면으로 확인했습니다.
- 구글은 사용자가 제공자 창에서 직접 로그인한 뒤 앱 복귀와 Google 계정 표시를 확인했습니다. 새로고침 후에도 같은 제공자의 로그인 복원이 확인되었습니다.
- 친구용 닉네임 미등록 계정의 상태조회404를 발견했습니다. 일반 오류 대신 프로필의 친구 화면에서 닉네임을 저장하도록 안내했습니다. 계정 등록·공개 설정을 임의 변경하지 않았습니다.
- 안내 변경은 타입 검사 및 서버 응원 관련3개 테스트 통과. 실제 친구 계정 간 응원/사진/좋아요 통합 검수는 별도이며 이번 로그인 성공으로 대체하지 않습니다.
