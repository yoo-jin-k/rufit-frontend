# 오운완 계정 저장과 좋아요 알림

## 사용 흐름
1. 로그인 후 친구 화면에서 닉네임을 저장합니다. 검색 허용 여부는 기존 선택을 유지합니다.
2. 운동 완료 후 오운완 작성에서 사진 0~5장과 글을 입력합니다.
3. 저장 위치를 이 기기 또는 내 계정으로 선택합니다. 계정 저장을 선택한 후에도 저장 버튼을 누르기 전에는 업로드하지 않습니다.
4. 공개 기본값은 나만 보기입니다. 친구 공개를 선택하면 현재 친구가 게시물과 사진을 볼 수 있습니다.
5. 프로필의 오운완에서 내 계정/이 기기를 전환할 수 있습니다. 저장 직후에는 선택한 위치를 열고 목록을 다시 읽습니다.
6. 친구 프로필에서 공개 게시물을 열어 좋아요를 누르면 작성자에게 알림이 생깁니다. 알림을 누르면 해당 게시물로 이동합니다.
7. 내 계정 게시물 상세에서 나만 보기로 변경하면 친구의 접근과 관련 좋아요 알림이 사라집니다.

## 저장·권한
- 기존 기기 기록은 자동 업로드하지 않습니다. 계정 저장에는 선택한 글·사진·운동 날짜·요약만 포함하며 세트별 운동 원본 동기화와 별개입니다.
- 같은 계정의 같은 운동은 동일 게시물로 저장합니다. 응답 유실 시 같은 내용 재전송은 중복 게시물을 만들지 않습니다. 다른 기기에서 바뀐 버전은 충돌로 안내합니다.
- 사진은 원본 2MB 이하 JPG/PNG, 최대1600만 화소를 검증하고 긴 변1280px 이하 JPEG로 다시 저장합니다. 위치 등 원본 메타데이터를 제거합니다.
- 초기 서버 버전은 사진을 PostgreSQL에 보관합니다. 목록은 작은 미리보기만, 상세는 인증과 공개 권한 확인 후 사진을 반환합니다. 계정당200게시물 제한이 있습니다.
- 비친구·차단 상태·나만 보기 게시물에는 타인이 접근하거나 좋아요를 누를 수 없습니다.

## 검증 결과
- 프론트 전체249개 테스트 통과, 스타일·타입 검사 통과. 최종 포맷 후 lint 오류0 / 기존 경고3. 저장 직후 목록 갱신 연결 후 타입 검사 추가 통과.
- 백엔드 전용 rufit_test DB에서 전체228개 테스트와 패키지 빌드 통과.
- 계정 저장 명시 선택, 글·사진 실패 보존, 동일 버전 재시도, 좋아요 실패 후 재시도·취소를 컴포넌트 테스트로 검증했습니다.
- 사진 정상화, 잘못된 사진·큰 요청 거부, 저장 중복·버전 충돌, 본인·친구·비친구·차단 및 공개 해제 권한, 좋아요 알림 중복과 소유권을 서버 테스트로 검증했습니다.
- 로컬 로그인 서버에 V32/API 반영. health200/UP, 미인증 게시물 조회401 확인. 실제 회원 기록이나 관계를 테스트로 변경하지 않았습니다.
- 브라우저 제어 연결이 끊겨 이번 신규 흐름의 실제 두 계정 간 브라우저 조작과 모바일 실기기 시각 검수는 미실시입니다.

## 후속 작업
- 운동 중 상태·응원 서버 이벤트와 알림.
- 출시 전 사진 객체 저장소 이전, 게시물 삭제 및 다른 기기에서 본문·사진 편집 UX, 실제 기기 권한·업로드·레이아웃 검수.
- OS 푸시는 별도이며 현재 알림은 앱 안에서 조회합니다.
