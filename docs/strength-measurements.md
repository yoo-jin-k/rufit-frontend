# 삼대측정·체중측정 — 2026-10-30

## 확정 동작
- 운동 화면 상단에 삼대측정·체중측정 메뉴. 모달로 진입하여 기존 운동 화면과 타이머 상태를 유지한다.
- 날짜당 하나의 기록. 같은 날짜 선택 시 기존 값 불러오기, 명시적인 수정 버튼으로 교체.
- 삼대: 벤치프레스·스쿼트·데드리프트 세 값 모두 입력. 0 초과 1,000kg 이하, 소수 둘째 자리까지. 실제 중량이며 추정 1RM 계산 아님.
- 체중: 0 초과 700kg 이하, 소수 둘째 자리까지.
- 오늘/과거 날짜 허용. 웹 달력 선택, 네이티브 YYYY-MM-DD 직접 입력. 로컬 날짜 기준.
- 사용자 후속 요청에 따라 누적 막대는 제거하고 **선 그래프**로 변경. 삼대 합계·벤치·스쿼트·데드 중 선택. 체중도 동일한 공통 선 그래프.
- 점의 가로 간격은 실제 날짜 간격에 비례. 한 기록은 점만, 두 기록부터 연결선. 점/날짜 버튼을 누르면 해당 수치 표시, 수정 버튼으로 입력창 이동.
- 삼대 세로축은 0부터. 체중은 작은 변화를 읽을 수 있도록 표시 범위를 조정하며 실제 축 값을 표시.
- 최근 수치는 가장 최근 측정 날짜 기준.

## 저장·구조
- 삼대 `rufit.strength.v1`: `{version:1, records:[{date, bench, squat, deadlift}]}`.
- 체중 `rufit.bodyweight.v1`: `{version:1, records:[{date, weight}]}`.
- AsyncStorage 기기 내 보관. 백엔드 API/기기 간 동기화는 미구현.
- 저장 성공 후에만 그래프 갱신. 저장 중 중복 입력 방지, 실패하면 입력 보존. 손상/읽기 실패 데이터 덮어쓰기 금지.
- 화면·공통 그래프·날짜 입력·검증 분리. 공통 토큰/StyleSheet, 웹 날짜 입력 Sass.
