# 로컬 루틴 시작

## 목적
완료한 운동을 내 루틴으로 저장하고, 다음 운동에서 같은 종목·세트 구성과 마지막 무게·횟수를 바로 불러와 시작한다. 진행 중 기록을 수정해도 저장한 루틴과 과거 운동은 바뀌지 않는다.

## 사용자 흐름
1. 운동을 완료한다.
2. 완료 화면이나 이전 기록에서 `이 운동을 내 루틴으로 저장`을 누른다.
3. 운동이 없는 시작 화면의 `내 루틴` 목록에서 저장한 루틴을 확인한다.
4. `시작`을 누르면 별도의 새 운동이 생성되고 모든 세트는 미완료 상태로 시작한다.
5. 새 운동에서 무게·횟수·세트 완료를 바꿔도 루틴 원본은 유지된다.

## 저장
- 루틴은 운동 기록과 별도 AsyncStorage 키에 저장한다.
- 동일한 원본 운동에서 다시 저장하면 같은 ID를 갱신해 중복을 만들지 않는다.
- 최대 50개까지 저장한다.
- 손상된 저장 데이터는 빈 루틴으로 덮어쓰지 않고 오류로 처리한다.

## 현재 범위
- 완료 운동 → 루틴 저장
- 루틴 목록 → 새 운동 시작
- 앱 재실행 후 로컬 복구
- 루틴과 시작된 운동의 데이터 독립성

루틴 이름 직접 편집, 종목 순서 편집, 새 루틴을 빈 상태에서 만드는 전체 편집기는 아직 포함하지 않는다. 계정 서버 동기화도 이 로컬 실행 단위에서는 변경하지 않는다.
